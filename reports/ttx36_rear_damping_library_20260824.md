## 4. T08 意見書 §5.1「Balaton 反例」の定量化

反例（`ph12_rear0_s` が Donington より悪いのに P4/0.028）のリア構成を力で比較した。

| | R8 Donington RACE1（62%） | R4 Balaton RACE1（89%・P4） | Δ |
|---|---|---|---|
| バルブ 圧 / 伸 | `C45_16` / `R47_16` | `C4_18` / `R5_16` | 別コード |
| スプリング | 84 N | 80 N | −5% |
| プリロード | 15.5 | 13.5 | −2 |
| TOS | 188×8 | 120×12 | 別物 |
| link | 6 | 5 | 別物 |
| **圧側 @0.1 / 0.3 m/s** | **554 / 992 N** | **397 / 853 N** | **−28% / −14%** |
| **伸側 @0.1 / 0.3 m/s** | **938 / 1768 N** | **715 / 1542 N** | **−24% / −13%** |

**反例の位置づけが明確になった**: Balaton のリアは Donington より圧側 14–28%・伸側 13–24% **弱く**、
TOS も link も別物である。すなわち「高い `ph12_rear0_s` が無害である」ことを示すのではなく、
**まったく別のリア構成でその値に到達した**ことを示している。意見書 §5.1 の「反例は無効ではなく割り引くべき」
という扱いが、数値で裏づけられた。

## 6. ⚠ 制約（UI に明記済み）

1. **速度軸 overlay は引き続き無効**（Codex 監査 §1）。リアは制約が 1 つ多い —
   `SUSP_REAR` → damper shaft への換算に **link（レバー比）が必要だが未取得**。
2. 表示値は **damper shaft force であって wheel force ではない**。車輪換算には link が要る。
3. **フロントとリアの力を直接比較してはならない**（別ダンパー・リンク介在）。UI 注記に明記。
4. `C21X` / `R25` / `C9_H20 L15` は解決不能 = `—`。**推測で埋めていない**。
