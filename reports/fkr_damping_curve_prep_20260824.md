## 3. 意見書 §5.2 の再検証 — clicker がニュートンになった

「reb 21 と 12」はスプリングもバルビングも違えば比較できない数字だった。実測カーブで変換すると:

| Run | comp key | reb key | F_comp@0.1 | **F_reb@0.1** | **F_reb@0.3** |
|---|---|---|---:|---:|---:|
| **R8 Donington（全 8 run 共通）** | C106_20 | R104_21 | 100.4 N | **76.5 N** | **298.5 N** |
| R4 Balaton RACE1（P4 / 0.028） | C104_20 | R104_18 | 99.4 N | 85.2 N | 331.5 N |
| R7 Misano RACE2（P5 / 0.275） | C104_16 | R104_12 | 119.4 N | 125.9 N | 441.5 N |

**JA52・2026 シーズン全体での F_reb@0.3 の範囲は 298–486 N。Donington の 298.5 N は
その最小値であり、しかも週末を通じて 8 run すべて同一だった。**

| Round | 回路 | n | F_reb@0.3 [N] | F_comp@0.3 [N] |
|---|---|---:|---|---|
| ROUND1 | PHILLIPISLAND | 12 | 308–394 | 390–510 |
| ROUND2 | PORTIMAO | 12 | 332–486 | 366–386 |
| ROUND3 | ASSEN | 12 | 332–486 | 366–448 |
| ROUND4 | BALATON | 8 | 332 | 334–390 |
| ROUND5 | MOST | 12 | 298–442 | 334–390 |
| ROUND6 | ARAGON | 7 | 332 | 366–404 |
| ROUND7 | MISANO | 11 | 307–442 | 366–406 |
| **ROUND8** | **DONINGTON** | **8** | **298（全 run 同一・季最小）** | 390–422 |

ライダーの Donington コメント `when off the brake F_Sus back quit fast` は、**季最小の伸側減衰力と
一致する**。意見書 §5.2 の仮説は clicker 比較から実測力の比較に格上げされた。

**ただし公平を期すこと。** Donington は季最小の伸側減衰でありながら**季最良の結果（P3/P6）**を
出している。したがってこのデータは「伸側が弱いと遅い」を意味しない。意味するのは
**ライダーの特定の訴えが、測定可能な最小値と一致している**ことだけである。意見書 §6-3
（フォークを決勝仕様へ戻して試す）の根拠にはなるが、それ以上の主張はできない。

補足: 圧側は Donington C106_20 = 100.4 N と Balaton C104_20 = 99.4 N がほぼ同値。
**同じクリック数でもコードが違えば力は別物**であり、逆にコードが違っても偶然一致することがある
という実例で、clicker 直接比較の危うさを示している。

## 4. 2D 速度と重ねるための較正（**未解決・最重要**）

カーブの横軸は **damper shaft speed [m/s]**、`lap_suspension.brk_f_dive_spd_*` は
**距離グリッド上の相対指数**であり、そのまま重ねてはならない。

### 4.1 指数のバイアス構造

実装（[build_master_db.py](../build_master_db.py) の `_vel`）は

```text
v_i = gradient(SUSP_FRONT) / dtg ,  dtg = lap_time / M
```

で、`M` 点の**距離グリッド**に対し **1 点あたりの時間を一律 `dtg`** としている。実際の
1 点あたり時間は `ds / v_i`（`v_i` = その地点の車速）なので、

```text
真の速度 / 指数  =  v_zone / v_harmonic_mean(lap)
```

**低速区間では指数が過大、高速区間では過小**に出る。KB の「校正済み絶対 mm/s ではない」という
注記はこの構造に対応する。

### 4.2 一次補正の見込み

`lap_suspension` は既にゾーン別平均車速を持っている（`brk_spd_avg` / `apex_spd_avg` / `ce_spd_avg`）。
`v_harmonic_mean = コース長 / lap_time` が分かれば、ゾーンごとの補正係数が直接出せる。

ROUND8 Donington JA52 の例: `brk 157.3 / apex 101.2 / ce 146.3 km/h`、`lap 94.63 s`。

→ **不足している入力はコース長ただ 1 つ。** これが入れば

- ブレーキング区間の補正係数はおそらく 1 に近い（= 指数がほぼ真の mm/s）
- APEX 区間は 1 を大きく下回る（= 指数が過大）

という予測を検証でき、**フォークは damper shaft ≒ fork travel（1:1）**なので、
フロントについては重ね合わせが定量的に成立する見込みがある。

### 4.3 リアは追加の未知数

リアは `link`（レバー比）を経由するため、`SUSP_REAR` 速度 → damper shaft 速度の換算が必要。
`link = 6` の定義は未取得（意見書 §8 の未解決項目）。加えてリアショックのカーブ自体が本ライブラリに
無い（§1）。**リアの重ね合わせは当面不可。**
